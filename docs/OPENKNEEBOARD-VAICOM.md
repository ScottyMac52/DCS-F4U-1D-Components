# OpenKneeboard and VAICOM PRO

The OvGME package installs three 1200 x 1600 reference pages under:

KNEEBOARD\F4U-1D

OpenKneeboard should discover that directory through its DCS Aircraft tab. If it
does not, add the directory as a Folder tab.

The pages divide airframe/carrier controls from stores/emergency-release controls and
the dual Logitech engine-control quadrants.
They are static and have no network dependency. The package does not change VAICOM PRO or
VoiceAttack configuration, so existing voice-command and kneeboard-navigation
profiles remain untouched.
