# WINCTRL CarrierAce PTO2

The F4U-1D profile is intentionally limited to the Corsair's carrier and
ground-handling controls.

| Physical control | Buttons | Behavior |
|---|---|---|
| WING FOLD lever | 28 / 29 / 30 | Fold / hold / spread |
| WING FOLD push | 31 | Independent wing-lock toggle |
| HOOK lever | 32 / 33 / 34 | Up / parking / down |
| GEAR lever | 35 / 37 | Up / down |

The OpenKneeboard page places a photographed PTO2 between the mapped-control callouts.
Every other PTO2 control is deliberately unbound; weapons, lighting, flaps, airbrake,
and parking-brake assignments from the source export are outside issue #1.
