# WINCTRL CarrierAce PTO2

The F4U-1D profile preserves all 25 assignments in Scott's current DCS export and
uses analogous PTO2 controls for the Corsair's airframe, carrier, and stores systems.

| PTO2 group | Buttons | F4U-1D behavior |
|---|---|---|
| FLAP | 5 / 7 | Flaps increase / decrease |
| LDG/TAXI LIGHT | 8 / 9 | Approach light on / off |
| ANTI SKID | 10 / 11 | Airbrake up / down |
| Stores station controls | 17 / 19 / 22–27 | Drop-tank lock, release selectors, and emergency releases |
| WING FOLD lever | 28 / 29 / 30 | Fold / hold / spread |
| WING FOLD push | 31 | Independent wing-lock toggle |
| HOOK lever | 32 / 33 / 34 | Up / parking / down |
| GEAR lever | 35 / 37 | Up / down |
| PARK BRK | 38 / 39 | Off / on |

Two OpenKneeboard pages place a photographed PTO2 between the mapped-control callouts.
The split keeps all 25 assignments readable in VR while preserving the working export
without redesigning Scott's control scheme.
