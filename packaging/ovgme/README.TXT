DCS F4U-1D CORSAIR COMPONENTS — OVGME PACKAGE
==============================================

OVGME PACKAGE VERSION {{VERSION}}
Target:  DCS Saved Games directory

This package installs Scott's GUID-qualified WINCTRL CarrierAce PTO2 profile to:

  Config\Input\F4U-1D\joystick

It also installs the photo-backed reference page to:

  KNEEBOARD\F4U-1D

The PTO2 controls landing gear, the three-position arresting hook, the
three-position wing-fold lever, and the independent wing-lock toggle. All other
PTO2 controls are intentionally unbound.

Before enabling the package, back up:

  Saved Games\DCS.openbeta\Config\Input\F4U-1D

If your Saved Games installation uses DCS instead of DCS.openbeta, use that root.

Disable the package in OvGME to remove the managed files.

OpenKneeboard should discover KNEEBOARD\F4U-1D through its DCS Aircraft tab.
If not, add that directory as a Folder tab.
